# 전환 매뉴얼 — 지금 구조에서 백그라운드 런처 형식으로

> **쓰는 법** : 이 파일을 클로드 코드(또는 쓰던 AI)에 열어 두고,
> 각 단계의 «붙여넣을 문장» 을 그대로 붙여 넣고 엔터. 한 단계 끝날 때마다 «확인» 을 돌린다.
> 확인이 통과하지 않으면 **다음 단계로 가지 않는다.** 어느 단계에서든 «되돌리기» 로 원상복구된다.
>
> 한 단계는 5~15분. 전부 6단계.

---

## 전환 전후 (무엇이 바뀌는가)

```
지금                                   전환 뒤
Revit ──BSP.Hub.addin──▶ BSP.Hub      Revit ──플랫폼.addin──▶ 플랫폼 ──첫 클릭──▶ BSP.Hub
  · 리빗 켜질 때 전부 로드                · 필요할 때만 로드 (기동이 빨라진다)
  · 업데이트 = 사람이 파일 복사            · 매니저가 받아서 갈아끼운다
  · 누가 무엇을 쓰는지 기록 없음           · 실행·메모리·사고가 전부 남는다
  · 리빗이 꺼지면 아무것도 안 돎           · 매니저는 리빗과 무관하게 산다
```

---

## 0단계 — 지금 상태를 찍고, 되돌릴 수 있게 만든다

```powershell
cd <SDK 폴더>
.\AI\snapshot.ps1          # 지금 상태 보관 (Addins 폴더 + 설정)
.\AI\healthcheck.ps1       # 지금 무엇이 깔려 있나
```

**확인** : `보관 완료 : …(파일 N개)` 가 나오고, `Addins\2024` 목록에 지금 쓰는 `.addin` 들이 보인다.

**되돌리기** (어느 단계에서든 · 리빗 닫고) : `.\AI\snapshot.ps1 -Restore`

> 이 단계를 건너뛰지 않는다. 뒤 단계는 전부 이 보관본을 믿고 진행한다.

---

## 1단계 — 매니저(백그라운드 런처)를 띄운다

아직 리빗은 건드리지 않는다. 밖에서 프로그램 하나가 도는 것뿐이다.

**붙여넣을 문장**

```
SDK 의 bin\bsp-launcher.exe 를 이 PC 에 설치해줘.
 · 설치 위치 : %AppData%\BSP\Platform\
 · config.json 은 templates\config.json 을 기준으로 만들되 server 는 비워 둬 (아직 서버 없음)
 · 로그온할 때 자동으로 watch-revit 모드로 뜨게 시작프로그램에 바로가기를 만들어줘
 · 관리자 권한이나 서비스 등록은 쓰지 마
설치 후 AI\healthcheck.ps1 을 돌려 결과를 보여줘.
```

**확인** — `healthcheck` 에서
- `매니저 : 돌고 있음 (pid …)` — **하나만**
- `심장박동 : 60초 이내`
- `서버 : 끊김 / 오프라인` ← 정상이다. 아직 서버가 없다

**이 단계에서 아무것도 깨지지 않는다.** 리빗은 여전히 예전 그대로 뜬다.

---

## 2단계 — 파일 하나를 배포해 본다 (서버 없이)

공유 폴더나 로컬 폴더를 «서버» 로 써서 배포가 실제로 도는지 본다.

```powershell
.\AI\selftest.ps1
```

**확인** — `5 PASS · 0 FAIL`

| 항목 | 이게 통과하면 |
|---|---|
| 설치 | 카탈로그에 적은 자리에 파일이 놓인다 |
| 해시 | 받은 파일이 올린 파일과 같다 |
| 변조 거부 | 파일이 바뀌어 있으면 **깔지 않는다** |
| 새 버전 | 옛 파일을 지우고 새것을 놓는다 |
| 서버 정지 | 서버가 없어도 PC 는 멀쩡하다 |

> 여기까지가 «배포가 성립한다» 의 증명이다. 서버는 나중에 붙여도 된다 —
> `manifestUrl` 에 공유 폴더 주소(`file://\\파일서버\bsp\catalog.json`)를 넣으면 그대로 배포된다.

---

## 3단계 — 리빗에 플랫폼 엔트리포인트를 얹는다

리빗 안에 **[BSP] 탭 + [상태] 버튼 하나**가 생긴다. 기존 애드인은 그대로 둔다.

**붙여넣을 문장**

```
리빗을 닫은 상태에서 SDK 의 src\Entry\build.ps1 -Install 로
BSP.Platform.Entry 를 Addins\2024 에 설치해줘.
기존 .addin 들은 하나도 건드리지 마. 설치 후 healthcheck 로 확인해줘.
```

**확인** — 리빗을 켠 뒤
1. 리본에 **[BSP]** 탭 · **[상태]** 버튼이 있다
2. [상태] 를 누르면 «매니저가 돌고 있습니다» + 상태 폴더 경로가 보인다
3. `healthcheck` 의 `기록` 에 `기동 … ok … ms` 줄이 생겼다 (**200ms 미만이어야 한다**)
4. 기존 애드인(HTS 등)이 **전과 똑같이** 뜬다

**되돌리기** : 리빗 닫고 `.\AI\snapshot.ps1 -Restore`

---

## 4단계 — 리빗 안에서 «받기» 를 눌러 본다

```
AI\selftest.ps1 에서 쓴 것과 같은 방식으로 시험용 제품 하나를 만들고,
리빗 안에서 Requests.Install("<제품id>") 를 불러 설치되는지 보여줘.
결과 문구(설치됨 / 다음 기동에 적용)를 그대로 화면에 띄워줘.
```

**확인**
- 누른 지 **2~3초 안에** 답이 온다
- 새 도구는 «설치됨», 이미 리빗이 물고 있는 파일은 «다음 기동에 적용»
- `%AppData%\BSP\Platform\cmd\` 에 요청 파일이 남아 있지 않다 (처리되면 지워진다)

> «다음 기동에 적용» 은 고장이 아니다. 리빗이 쥔 DLL 은 리빗 자신도 못 바꾼다.
> 화면이 그 사실을 사용자에게 말해 주는 것이 이 단계의 목적이다.

---

## 5단계 — 기존 애드온(HTS)을 플랫폼 위로 옮긴다

**여기가 본 작업이다.** 지시서는 따로 있다 → `AI\ADAPT_HTS.md`

**붙여넣을 문장**

```
AI\ADAPT_HTS.md 를 읽고 그대로 진행해줘.
HTS 를 kind=bridged 제품으로 패키징하고, .addin 은 빼고, 플랫폼이 도구를 싣게 해줘.
도구 소스는 고치지 말고 로드 경로만 바꿔. 끝나면 그 문서의 합격 기준 6개를 하나씩 확인해줘.
```

**확인** (전부 리빗 안에서)

| # | 확인 | 통과 |
|---|---|---|
| 1 | 도구 수 | 플랫폼 탭의 버튼 수 = 원래 도구 수 (HTS 는 33개) |
| 2 | 탭 | HTS 자기 탭이 **없다**. [BSP] 탭 하나 |
| 3 | 지연 로드 | 리빗 켠 직후엔 `BSP.Hub.dll` 이 안 올라와 있고, 첫 클릭 뒤에 올라온다 |
| 4 | 실행 | 도구 3개를 눌러 전부 정상 · `healthcheck` 기록에 `succeeded` |
| 5 | 기동 | 기동 추가 시간 200ms 미만 |
| 6 | 사고 | 세션 끝까지 `crash.attributed` 없음 |

**미리 알고 갈 것 두 가지**
- HTS 실제 참조는 `RevitAPI 21.x` 다 (라벨은 2024). **2024 로 다시 빌드하지 않으면
  버튼 누르는 순간 죽는다.** 재빌드가 안 되면 그 도구는 2024 대상에서 내린다
- 서명이 없어 검사에서 `코드 서명 FAIL` 이 난다. 인증서 결정 전까지는 사내에서만 쓴다

---

## 6단계 — 서버를 붙인다 (원하는 대로)

여기부터는 그쪽 몫이다.

```
AI\SERVER.md 를 읽고 그대로 만들어줘. 언어와 틀은 네가 정해도 된다.
다 만들면 AI\selftest.ps1 -ManifestUrl <내 주소> 로 합격 시험을 돌리고 결과표를 보여줘.
```

**확인** : `selftest` 6항목 전부 PASS. 그다음 `config.json` 의 `manifestUrl` 을 그 주소로 바꾸면
전 PC 가 그 서버에서 받기 시작한다. **런처는 한 줄도 고치지 않는다.**

## 단계 요약표

| 단계 | 바뀌는 것 | 리빗 영향 | 확인 |
|---|---|---|---|
| 0 | 없음 (보관) | 없음 | 보관본 생성 |
| 1 | 매니저 상주 | 없음 | healthcheck : 매니저 1개 |
| 2 | 없음 (시험) | 없음 | selftest 5/5 |
| 3 | [BSP] 탭 추가 | 탭 하나 늘어남 | 상태 창 · 기동 <200ms |
| 4 | 없음 (시험) | 없음 | 왕복 2~3초 |
| 5 | **HTS 로드 방식** | 탭 통합 · 지연 로드 | 합격 6개 |
| 6 | 배포 출처 | 없음 | selftest 6/6 |

## 막혔을 때

| 증상 | 먼저 볼 것 |
|---|---|
| 매니저가 안 뜬다 | `%AppData%\BSP\Platform\agent.err.log` |
| 리빗이 기동에서 오래 멈춘다 | 서명 없는 애드인 대화상자 (실측 1시간 45분) |
| 버튼은 뜨는데 누르면 죽는다 | 그 도구의 RevitAPI 참조 연도 (21.x 로 빌드된 것) |
| 도구가 통째로 사라졌다 | 남의 설정 파일(`products.txt`)을 건드렸는지 |
| 업데이트가 반영이 안 된다 | 리빗을 껐다 켰는지 · `healthcheck` 의 «대기» 목록 |
| 무엇이 잘못됐는지 모르겠다 | `.\AI\snapshot.ps1 -Restore` 로 되돌리고 다시 |
