## 3. 오늘 찾아낸 HTS 문제

### ① Revit 2021 API 로 빌드돼 있다 ★
```
HTS DLL 4개 참조 : RevitAPI <내부주소>  (Revit 2021)
실행 중            : RevitAPI <내부주소>  (Revit 2024.2)
BuiltInCategory    : System.Int64      (2024 에서 32→64비트)
```
About 에는 «Revit 2024 Only» 라고 적혀 있다. **라벨과 실체가 다르다.**

**증상** : 탭·버튼 33개는 정상으로 뜨는데, `BuiltInCategory` 배열을 건드리는 도구가 실행 순간 죽는다.
```
TypeInitializationException — BSP.LinkLabel3D.Core.DwgLayers..cctor()
  → ArgumentException: 값이 예상 범위를 벗어났습니다 (RuntimeHelpers.InitializeArray)
```
**죽는 것 확인** : `Export CAD`, `Filter Set` (둘 다 같은 원인)
**고치는 법** : 2024 API 로 재빌드 한 번. 소스 필요 (`<사내 저장소>\BSP.LinkLabel3D` — 이 PC 에 없음)

### ② 서명이 없다
새 DLL 을 깔 때마다 «보안 — 서명 없는 애드인» 대화상자가 뜨고, 답할 때까지 리빗이 멈춘다.
오늘 실측 **1시간 45분 정지**(11:02 기동 → 12:47 애드인 로드). 무인·전사 배포가 성립하지 않는다.

### ③ 기동이 느리다 — 그런데 남의 탓이다
같은 HTS 가 **8분 → 16초**. 차이는 pyRevit 확장(BSPISO 726MB 포함)이 같이 뜨느냐뿐.
지금은 아무도 이 지연을 재지 않는다.

### ④ 기록이 0 이다
누가 무엇을 눌렀는지, 왜 느렸는지, 왜 죽었는지 남는 곳이 없다.
리빗 저널에는 **세션당 참조 불일치 53건 / 51종**이 찍히는데 아무도 안 본다.

### ⑤ 팝업이 겹친다
HTS 자체 도킹 패널 3개(Filter Set · My View · 도구상자) + 우리 것 2개 = 화면이 덮인다.
→ 탭 전환에 따라 그쪽 것만 열리게 처리함(0.8.1).
