## 이 논의에서 나온 사실들 (전부 실측)

| 선언 연도와 참조 `RevitAPI` 가 다르면 **버튼 누르는 순간** 죽는다 (`BuiltInCategory` 32→64비트) | 실측 |
| 남의 제품 설정 파일(`products.txt`)을 건드리면 도구 33개가 통째로 사라진다 | 사고 |
| Job(kill-on-close) 안에서는 그냥 자식으로 띄우면 부모와 함께 죽는다 | 실측 |
| .NET 기본 HTTP 캐시 때문에 새 카탈로그가 안 보인다 | 실측 |
| 옛 버전을 먼저 지우고 받으면 실패했을 때 **아무것도 없는** PC 가 남는다 | 실측 |
| 요청 → 받기 → 검증 → 배치 왕복 **1.3초** | 실측 |
