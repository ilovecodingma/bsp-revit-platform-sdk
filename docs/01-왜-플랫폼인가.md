# 왜 플랫폼인가 — 만들 것과 안 만들 것 (2026-09-21)

> 오늘 PoC 와 실측에서 나온 것만으로 적었다. 추정은 «추정» 이라 표시했다.

## 0. 한 줄

**우리는 애드온을 만들지 않는다. 애드온이 리빗 안에서 같이 살 수 있게 중재하고, 그 자격을 검사한다.**
제품의 심장은 스토어가 아니라 **적합성 검사 엔진**이다. 스토어·런처·수수료는 그 엔진이 있어야 성립한다.

---

## 1. 만들 것과 안 만들 것

| | 무엇 | 출처 |
|---|---|---|
| **안 만든다** | 연도별 Revit API 참조 | Nice3point NuGet (2027까지 있음) |
| | 개발 편의 라이브러리·템플릿 | RevitToolkit |
| | 파이썬 실행 환경 | pyRevit 그대로 |
| | 외부 유통·결제 | Autodesk App Store (겹치지 않는다) |
| **만든다** | **적합성 검사 엔진** ★ | 없다 — 여기가 우리 자리 |
| | 매니페스트 규격 · 계약(`BSP.Contracts`) | PoC 에 초안 있음 |
| | 백그라운드 런처 | **완료** (C# net48 단일 exe, 17KB) |
| | 카탈로그 서버 · 콘솔 | **완료** (4모듈, 파이썬 참조본 → Spring 이관) |
| | 코드 서명 정책·키 보관 | 정책 미정 |

## 2. 구조 — 4층

```
[서버]   카탈로그 · 자산 · 해시 · 회원 · 판매자 · 집계 · 프로모션
   ▲ HTTPS (도메인 1개, 443, 인증서 고정 금지)
[런처]   상주. 받아오기 · 해시 검증 · 배치 · 잠김 큐 · 폴더 감시 · 기록 수거
   ▼ 파일 (state.json · runlog.jsonl)
[브릿지] 리빗 안. 매니페스트로 리본만 짓고, 클릭 때 로드. 실행 깔때기 · 기록
[애드온] HTS · 설계팀 · 타사. Run() 안쪽은 그들 것
```

**원칙 : 리빗 프로세스는 외부 통신을 하지 않는다.** 네트워크는 전부 런처가 한다.

## 3. 핵심 — 적합성 검사 엔진

### ① 정적 검사 (리빗 없이, 초 단위)

| 검사 | 근거 |
|---|---|
| 참조 `RevitAPI` 버전 == 선언 `targetRevit` | **오늘 사고**: HTS 가 <내부주소>(2021) 참조인데 «2024 Only» 로 배포됨 |
| 런타임 계열(net48/net8) ↔ 연도 | 2025+ 는 net8 강제 |
| 서명 유무·발급자·만료·체인 | **오늘 사고**: 서명 없어 리빗이 1시간 45분 대기 |
| 계약 구현 · 금지 API (자기 `.addin`, 전역 이벤트 직접 구독, 프로세스 조작) | 탭 난립 · 성능 |
| 동봉 금지 어셈블리 (`BSP.Contracts`, `RevitAPI*`) | 계약 분열 |
| 의존성 목록 → 충돌 예측 | 오늘 측정: 중복 어셈블리 **22종** |

### ② 실기 검사 (격리 Revit, 연도별)

**★ 모든 타입의 정적 초기화 강제 실행** (`RuntimeHelpers.RunClassConstructor`)
— 오늘 이 한 수로 `DwgLayers`·`UtilityFilter` 두 개를 버튼도 안 누르고 잡아냈다. 엔진의 주무기.

그 외 : 로드 여부 · **기동에 더한 ms** · 리본 생성 결과(자기 탭 만들었나) · 버튼별 스모크 ·
메모리·스레드 증가 · 종료 시 잔존물(`.running`).

### ③ 판정이 곧 카탈로그

제품 × 연도 매트릭스로 남긴다. `2021 PASS / 2024 FAIL(참조 불일치) / 2025 미검사`.
**런처는 자기 버전에서 PASS 인 것만 내려받는다.** 오늘 같은 일이 구조적으로 불가능해진다.

## 4. 정책 두 가지

**코드 서명** — Play 모델을 따른다. 입점사는 **업로드 키**, **배포 서명은 우리가 보관**.
회사 공인 인증서 1장으로 모든 입점 제품이 서명된 채 나간다 → 리빗의 «서명 없는 애드인» 창이 사라지고,
대기업 보안 심사의 진입 조건을 만족한다.

**버전 정책** — `Revit N, N−1, N−2` 지원. 새 연도 출시 후 **6개월 안에 `targetRevit` 을 올리지 않으면
카탈로그에서 내린다.** (Play 의 targetSdk 정책 차용 — 2026-08-31부터 API 36 강제, 못 맞추면 업데이트 차단)

## 6. 터질 문제 — 기술

| 문제 | 왜 | 대응 |
|---|---|---|
| **언로드가 없다** | .NET Framework. 한 번 올라간 DLL 은 세션 끝까지 | 격리를 포기하고 «다음 기동» 단위로 통제. 자동 격리는 다음 부팅에 적용 |
| **리본·패널은 기동 때만 만든다** | 리빗 구조 | 지연 로드는 «버튼은 미리, 내용은 클릭 때». 새 제품은 재시작 필요 — 문서에 명시 |
| **파일 잠김** | 리빗 실행 중 DLL 교체·삭제 불가 (오늘 실측) | 큐에 넣고 리빗 종료 시 적용. 런처가 자동 처리 (오늘 동작 확인) |
| **비공식 API 의존** | 탭 순서·색·탭 전환 감지는 AdWindows 반사 | 실패를 전부 삼킨다. 깨져도 기능은 살아 있게. 연도 올릴 때 회귀 검사 항목 |
| **연도 × 런타임 매트릭스 폭발** | 2021~2027 × net48/net8 | 지원 연도를 **명시적 목록**으로 좁힌다 (N, N−1, N−2) |
| **실기 검사에 Revit 머신이 필요** | 연도별 설치 + 라이선스 | 우리 사내 1대로 시작. 야간 배치 |
| **정적 초기화 강제 실행의 부작용** | cctor 가 파일·네트워크를 건드릴 수 있다 | 격리 머신 + 스냅샷 복원. 절대 사용자 PC 에서 돌리지 않는다 |
| **남의 설정 파일 오염** | **오늘 실제로 냈다** — 런처가 `products.txt` 를 덮어써 HTS 도구 33개가 전부 안 떴다 | 우리가 관리하는 제품의 파일만 만진다. 그 코드는 제거함 |
| **폐쇄망·프록시** | 기업망 SSL 인스펙션 | **인증서 고정(pinning) 금지**. 도메인 1개·443 고정 |

## 7. 터질 문제 — 조직

| 문제 | 대응 |
|---|---|
| **강제력이 기술이 아니라 정책에서 나온다** | 우리 문으로 들어오면 설치·판올림·설명서·오류보고를 공짜로 얻는 거래. 고객사 IT 규정(«승인 안 된 애드인 금지»)이 최종 근거 |
| **남의 제품은 소스 없이 못 고친다** | 오늘 HTS 재빌드가 막힌 이유. 검사로 «못 쓴다» 를 대는 데까지가 우리 몫 |
| **설계팀이 계약을 지키게 하기** | 사내도 타사와 같은 문·같은 검사. 차이는 발급 코드(등급)로만 |
| **대기업 보안 심사 리드타임** | 코드 서명·수집 항목 명세·외부 통신 0 모드를 미리 갖춰 둔다 |

## 8. 터질 문제 — 사업

| 문제 | 대응 |
|---|---|
| **서명 키 보관 책임** | 키가 새면 전사 사고. HSM·접근 기록·분리 보관. 키를 쥐는 대신 책임을 진다 |
| **사용 기록 수집 동의** | 수수료·프로모션의 근거인데 개인정보로 비칠 수 있다. 수집 항목을 문서로 고정(도면·설계 내용 제외) |
| **오토데스크 정책 변화** | 2027 에 MCP 기본 탑재 예정 등. 우리는 범용 MCP 를 만들지 않고 **업무 어휘·배포·중재**에 남는다 |
| **유지보수 인력** | 연도마다 재빌드·재검사. 지원 연도를 3개로 묶어 상한을 만든다 |

## 9. 오늘 실측 (조항 근거)

| 값 | 의미 |
|---|---|
| HTS 참조 API **<내부주소>** vs 실행 **<내부주소>** | «2024 Only» 인데 2021 빌드 |
| `BuiltInCategory` 기반 타입 = **Int64** | 2024 에서 32→64비트. 옛 빌드의 정적 배열이 깨진 이유 |
| 서명 없는 애드인 대화상자로 **1시간 45분** 정지 | 무인 배포 불가 |
| 리본 등록 **8분 → 16초** | pyRevit 확장(726MB) 끄자 단축. 남의 애드인이 기동을 먹는다 |
| 참조 불일치 **세션당 53건 / 51종** · 중복 어셈블리 **22종** | 리빗이 스스로 기록하는데 아무도 안 본다 |
| HTS 실행 기록 **0건** | 누가 무엇을 눌렀는지 남지 않는다 |
| 우리 플러그인 기동 **19~24 ms** | 중재 층을 얹어도 무겁지 않다 |

## 10. 정해 주셔야 할 것

1. **코드 서명 인증서** 구매 — 배포의 전제. 없으면 4단계 이후가 전부 막힌다
2. **지원 연도 3개** 를 무엇으로 할 것인가 (2024·2025·2026?)
3. **설계팀 도구의 소스 접근** 여부 — 없으면 «검사해서 반려» 까지만 가능
4. 실기 검사용 **사내 Windows 머신 1대**
